# App icon

`AppIcon.png` is the production icon source. It was created with the built-in image generation tool. Transparency around the rounded tile is preserved when packaging the macOS icon.

## Generation prompt

Use case: logo-brand. Asset type: production macOS application icon for PDF Press, a local PDF compression utility. Primary request: a professional, premium, restrained native Mac productivity app icon. Create a single finished icon, not a mockup or presentation. Subject: a crisp ivory-white document with a sharply folded upper-right corner and three short fine slate text strokes, flanked by two small sculpted turquoise compression arrows pointing toward the document from its left and right edges. The document is the dominant silhouette; arrows convey reducing file size and should be legible at 32px. Style: refined Apple macOS utility icon, subtle dimensional depth, precise geometric construction, satin surfaces and soft controlled lighting. Backplate: rounded-square deep steel-blue tile with a very gentle tonal gradient, thin soft edge highlight; centered on a truly transparent square canvas with equal 6% outer margin. Palette: steel blue, pearl white, cool silver, restrained turquoise. Composition: front view, square 1024x1024, one centered icon; no dramatic perspective. Constraints: actual transparency outside the rounded-square icon tile, generous clean silhouette, small-size readability, no lettering, no zipper, no bag, no emoji, no badge, no watermark, no busy scene, no heavy shadows, no playful cartoon style, no neon or gaudy gloss. Finished production icon only.
